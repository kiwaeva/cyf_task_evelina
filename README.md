## 🚀 Deployment Steps

1. **Create a GitHub Repository**
   * Log into GitHub and create a new repository.
   * Make sure to include your name in the repository name.

2. **Download CodePen Files**
   * Navigate to your project on CodePen.
   * Click the **Export** button in the bottom right corner and select **Download .zip**.

3. **Extract the Files**
   * Locate the downloaded `.zip` file on your computer.
   * Unzip/extract the contents into a local folder.

4. **Upload to GitHub**
   * Open your newly created GitHub repository in your browser.
   * Drag and drop your unzipped project files directly into the repository window to upload them.
   * Commit the changes.
